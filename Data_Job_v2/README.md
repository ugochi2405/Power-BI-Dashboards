# Data Jobs Dashboard w/ Power BI

![Dashboard Page 1](/Images/Project2_Page1.png)

## Introduction

This dashboard(V2.0) is designed specifically for **Job Seekers, Job Transtioners, and Job Swappers** to cut through the clutter. It provides a streamlined, single-page interface to quickly explore key market trends and compensation insights in the data job market.

## Skills Showcased

- **Dashboard Design:** Creating intuitive and visually appealing report layouts.  
- **Power Query (ETL):** Cleaning, shaping, and transforming raw data into usable formats.  
- **Data Modeling:** Building efficient models with relationships (using Star Schema principles).  
- **DAX Fundamentals:** Writing calculations and aggregations to derive key insights.  

### Visualizations Utilized
- **Core Charts:** Column, Bar, Line, and Area charts for comparisons and trend analysis.  
- **Map Charts:** Displaying geospatial insights effectively.  
- **Cards:** Highlighting key performance indicators (KPIs).  
- **Chart Variety:** Leveraging both common and uncommon chart types for impactful storytelling.  

### Interactive Features
- **Slicers:** Enabling dynamic, user-driven data filtering.  
- **Buttons & Bookmarks:** Streamlining navigation and enhancing the user experience. 

## Dashboard Overview

This **second iteration** consolidates the dashboard into a **single, focused page**,  
designed to provide job seekers with the most critical market insights at their fingertips.

![Dashboard Page 1](/Images/Project2_Page1.png)

This page serves as a **concise mission control** for the data job market.  
It highlights essential **Key Performance Indicators (KPIs):**  
- **Job Count**  
- **Skills per Job**  
- **Median Yearly Salary**  
- **Median Hourly Salary**  

### Additional Insights
- **Skill Popularity:** View by job percentage or job count.  
- **Salary Comparisons:** Analyze compensation across different job titles.  

All features are designed to provide an **efficient, at-a-glance overview** of the market.  


## Conclusion
This updated dashboard (Version 2.0) showcases **Power BI's** ability to transform extensive job posting data into a powerful, streamlined tool for career analysis.

It empowers **Job Seekers, Job Transitioners, and Job Swappers** by allowing them to filter and explore essential market insights efficiently on a single page, helping them make informed decisions about their next career move.
